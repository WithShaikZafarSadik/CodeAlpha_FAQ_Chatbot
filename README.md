# 🤖 CodeAlpha FAQ Chatbot

## 📌 Description
A simple FAQ Chatbot developed using Python and Tkinter. It answers common questions about CodeAlpha internships using predefined responses.

## ✨ Features
- Interactive chatbot interface
- Answers frequently asked questions
- Easy-to-use GUI
- Send, Clear Chat, and Exit buttons
- Fast responses

## 🛠 Technologies Used
- Python
- Tkinter

## 📂 Project Structure
- main.py
- ui.py
- chatbot.py
- responses.py
- preprocess.py
- requirements.txt
- README.md

## ▶️ How to Run

1. Install Python
2. Open the project folder
3. Run:

```bash
python main.py
```
